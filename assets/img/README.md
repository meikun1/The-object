# Изображения сайта

Здесь лежат реальные фотографии заведения. Файлы подключены в `css/styles.css`.

| Файл | Фото | Где используется |
|------|------|------------------|
| `hero.jpg` | Коктейль с неоном | Фон главного экрана |
| `cocktail.jpg` | Коктейль с неоном | Галерея |
| `atmosphere.jpg` | Зеркало в чёрной стене | Полоса «Атмосфера» + галерея |
| `hookah.jpg` | Ряд кальянов | Блок «Кальян» + галерея |
| `lounge.jpg` | Стол у окна | Галерея |
| `bar.jpg` | Зал, лукбук | Галерея |

## Замена

Просто положите новый файл с тем же именем (JPG/PNG/WebP) — сайт подхватит
его автоматически после коммита. Оптимально: ширина 1600-2000 px, WebP для
скорости. Все текущие кадры вертикальные; для фона hero и широких полос
лучше подойдут горизонтальные снимки, если будут.
