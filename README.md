# THE OBJECT — Lounge Bar

Современный одностраничный сайт лаунж-бара **THE OBJECT** в эстетике
**art-house noir / editorial luxe**: каждый коктейль и кальян подан как
«объект коллекции» (OBJ. 01, 02…). Тёплый чёрный + жидкий хром, резкий
кроваво-красный акцент, кастомный курсор, оркестрованная анимация загрузки,
бегущая строка, magnetic-кнопки, адаптив под телефоны.

Собран по методологии плагина **frontend-design** (anthropics/claude-code) —
с отказом от «генерических AI-шаблонов».

### Дизайн-система
- **Типографика:** Prata (контрастный дидон, дисплей) · Golos Text (кириллический
  гротеск, текст) · JetBrains Mono (мета, номера, цены).
- **Цвет:** доминанта `--void` (#0a0908) + хром, акцент `--blood` (#c01f33).
- **Движение:** прелоадер-счётчик, staggered reveal, вращающийся хром-эллипс,
  курсор-«объект», magnetic-кнопки, бегущая строка.

## Что внутри

| Раздел | Описание |
|--------|----------|
| **Hero** | Анимированный логотип-эллипс, неоновые линии, хром-блик, параллакс |
| **Атмосфера** | Текст о концепции + анимированные счётчики |
| **Барная карта** | Категории коктейлей (примеры — заменяются на ваши позиции) |
| **Кальянная карта** | Карточки кальянов + облако популярных вкусов |
| **Галерея** | Сетка под фото интерьера и подачи |
| **Контакты + бронь** | Реквизиты, соцсети и форма бронирования стола |

## Технологии

Чистые **HTML + CSS + JavaScript**, без сборки и зависимостей.
Шрифты — Google Fonts (Cinzel, Cormorant Garamond, Manrope).

## Запуск локально

Просто откройте `index.html` в браузере. Либо поднимите локальный сервер:

```bash
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

## Публикация

Сайт статический — заливается на любой хостинг: GitHub Pages, Netlify,
Vercel, обычный shared-хостинг. Для GitHub Pages достаточно включить Pages
для ветки в настройках репозитория.

## Что заменить под себя

- **Меню** — позиции и цены в `index.html` (секции `#bar` и `#hookah`).
  Пришлите вашу барную и кальянную карту — впишу.
- **Контакты** — адрес, телефон, ссылки соцсетей, часы работы (секция `#contacts`).
- **Галерея** — добавьте фото в `assets/` и подставьте в `.gallery__item`.
- **Форма брони** — сейчас показывает демо-подтверждение. Можно подключить
  отправку на e-mail, в Telegram-бот или CRM (см. комментарий в `js/main.js`).
