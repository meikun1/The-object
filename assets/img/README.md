# Изображения сайта

Сайт ссылается на 6 файлов в этой папке. Пока файлов нет, блоки
показывают аккуратный тёмный градиент (graceful fallback), поэтому сайт
не выглядит «сломанным». Как только положите файлы с этими именами,
фотографии появятся автоматически.

| Файл | Где используется | Рекомендуемый кадр / пропорции |
|------|------------------|--------------------------------|
| `hero.webp` | Фон главного экрана | Тёмный интерьер бара, горизонтальный, ~16:9 |
| `atmosphere.webp` | Блок «Атмосфера» (широкая полоса) | Интерьер, деталь, ~21:8 |
| `cocktail.webp` | Галерея (большой кадр) | Коктейль/подача, вертикальный |
| `bar.webp` | Галерея | Барная стойка, горизонтальный |
| `lounge.webp` | Галерея | Зал/посадка, горизонтальный |
| `hookah.webp` | Блок «Кальян» + галерея | Кальян, дым, вертикальный |

## Что положить

Лучше всего — **реальные фотографии вашего заведения** (они всегда
сильнее стоковых или сгенерированных). Подойдут JPG/PNG/WebP; просто
сохраните их под именами из таблицы. Для скорости загрузки оптимально
WebP шириной 1600-2000 px.

Если своих фото под рукой нет, я могу сгенерировать атмосферные
noir-изображения под бренд (тёмный фон, хром, тёплый свет).
