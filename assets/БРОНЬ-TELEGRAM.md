# Бронь → Telegram (настройка за ~10 минут)

Заявки с формы отправляются в Telegram через бесплатный посредник
(Cloudflare Worker). Токен бота хранится секретно на Cloudflare и **не
попадает в публичный код сайта**.

## 1. Создать бота и узнать ID чата

1. В Telegram напишите **@BotFather** → `/newbot` → получите **токен**
   (вид `123456:ABC...`).
2. Создайте рабочую группу, **добавьте туда бота**.
3. Узнайте **chat_id** группы: добавьте в группу **@RawDataBot** (или
   @getmyid_bot), он покажет `chat_id` (для групп он отрицательный,
   например `-1001234567890`). После этого бота-помощника можно удалить.

## 2. Развернуть Worker на Cloudflare

1. Зарегистрируйтесь на **dash.cloudflare.com** (бесплатно).
2. **Workers & Pages → Create → Worker** → задайте имя
   (напр. `the-object-booking`) → **Deploy**.
3. **Edit code** → вставьте содержимое файла
   `assets/telegram-booking-worker.js` из этого репозитория → **Deploy**.
4. **Settings → Variables and Secrets** → добавьте секреты:
   - `BOT_TOKEN` — токен из BotFather
   - `CHAT_ID` — id вашей группы
   - *(опционально)* `ALLOWED_ORIGIN` — `https://meikun1.github.io`
5. Скопируйте адрес воркера, вид
   `https://the-object-booking.ВАШ-ЛОГИН.workers.dev`.

## 3. Подключить к сайту

В файле `js/main.js` впишите адрес воркера в строку:

```js
const BOOKING_ENDPOINT = 'https://the-object-booking.ВАШ-ЛОГИН.workers.dev';
```

Закоммитьте — и форма начнёт слать заявки в ваш чат. Пока строка пустая,
форма просто показывает подтверждение, без отправки.

## Проверка
Отправьте тестовую заявку с сайта — в группе должно появиться сообщение
«🍸 Новая бронь — THE OBJECT» с именем, телефоном, датой и временем.
